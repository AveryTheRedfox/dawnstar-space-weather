
A Dashboard for monitoring currnt Space Weather events on a single monitor!

Running this on a e.g Raspberry Pi on a single Monitor is preferred. An Internet connection is required to run this however as the data is pulled from the server of the SWPC (Space Weather Prediction Center)

KNOWN ISSUE: 

The current and all precursor versions have a memory leak issue which will be fixed!

This project was bootstrapped with Create React App.
